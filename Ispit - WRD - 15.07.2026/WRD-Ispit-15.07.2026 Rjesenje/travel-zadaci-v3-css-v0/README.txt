TRAVEL — STARTER PROJEKAT
=========================

POKRETANJE
----------
1. Otvoriti ovaj folder u Visual Studio Codeu.
2. Pokrenuti index.html preko Live Servera.
3. Ponude se automatski preuzimaju sa WRD API-ja.

STRUKTURA
---------
index.html                 Glavna stranica
styles/style.css           Osnovni scaffold; student implementira CSS dio ispita
styles/booking.css         Unaprijed pripremljeni stilovi rezervacije
scripts/script.js          JavaScript starter
assets/                    Lokalne slike i fontovi
screenshots/               Referentne PNG slike zadatka

NAPOMENA
--------
Tekst zadataka i bodovanje nalaze se u ispitnom dokumentu.
Dozvoljeno je mijenjati zadani HTML.
Lokalni fontovi, CSS varijable i osnovni reset već su pripremljeni.
Datoteku styles/booking.css nije potrebno mijenjati.
Datoteka styles/style.css sadrži jasno označen privremeni DRAFT CSS koji
olakšava testiranje JavaScripta. Za CSS dio ispita taj blok treba obrisati.
Ovo je CSS starter varijanta 0: gotovo potpuno nestilizirana stranica.
